# Contribuir

## Convenciones
- **Commits:** Conventional Commits (feat:, fix:, chore:, docs:, refactor:)
- **Estilo:** Prettier + EditorConfig
- **PRs:** Incluye descripción, capturas y checklist de pruebas.

## Revisión de código
1. Abre PR hacia `main`.
2. Al menos 1 revisor.
3. Pasa pruebas locales (si aplican) y linters.

## Issues
- Usa etiquetas: `frontend`, `backend`, `bug`, `enhancement`, `design`, `docs`.
- Describe _qué_ ocurre, _qué_ esperas, pasos para reproducir y evidencia (logs/capturas).
